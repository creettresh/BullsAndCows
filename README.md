# Бики та Корови (Bulls and Cows)

Логічна гра з цифрами у браузері. Один файл `index.html`, без встановлення.

**▶ Грати:** https://creettresh.github.io/BullsAndCows/

## Як грати

Суперник загадує число з 3 або 4 різних цифр. Після кожної спроби ти отримуєш підказку:

- **Бик** — цифра є в числі і стоїть на своєму місці.
- **Корова** — цифра є в числі, але стоїть на іншому місці.

Приклад для 3 цифр: загадано `470`.

| Спроба | Підказка | Пояснення |
|---|---|---|
| `123` | 0 Б, 0 К | жодної з цих цифр немає |
| `407` | 1 Б, 2 К | 4 на своєму місці, 0 і 7 переплутані |
| `470` | 3 Б | вгадано |

## Режими

- **Ти вгадуєш** — комп'ютер загадує число, ти відгадуєш.
- **Він вгадує** — ти загадуєш число на папері й підказуєш комп'ютеру бики та корови.
- **Дуель** — ви з комп'ютером загадуєте числа й вгадуєте по черзі. Нічия, якщо обидва вгадали в одному раунді.
- **Онлайн** — гра з другом на іншому телефоні. Один створює кімнату й надсилає код або посилання, другий приєднується. Ви обидва загадуєте числа й вгадуєте одночасно, раунд за раундом.

Комп'ютерний суперник має два рівні: **легкий** пам'ятає лише три останні підказки, **середній** враховує всі.

## Онлайн-режим

Телефони з'єднуються напряму (WebRTC) через безкоштовний сервіс [PeerJS](https://peerjs.com/), власний сервер не потрібен.

- Кожен рахує бики й корови для своєї таємниці сам, тому твоє число не передається супернику до кінця гри.
- Після гри числа відкриваються, і гра перевіряє, чи суперник чесно рахував бики й корови.
- Кількість цифр обирає той, хто створює кімнату.
- Якщо обидва гравці на мобільному інтернеті різних операторів, з'єднання інколи не встановлюється. Тоді допомагає, коли хоча б один перейде на Wi‑Fi.

## Запуск

Відкрий `index.html` у браузері. Онлайн-режиму потрібен інтернет.
