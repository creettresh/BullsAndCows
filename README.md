# Бики та Корови (Bulls and Cows)

Логічна гра з цифрами у браузері. Один файл `index.html`, без встановлення та залежностей.

## Як грати

Суперник загадує число з 3 або 4 різних цифр. Після кожної спроби ти отримуєш підказку:

- **Бик** — цифра є в числі і стоїть на своєму місці.
- **Корова** — цифра є в числі, але стоїть на іншому місці.

Приклад для 3 цифр: загадано `470`.

| Спроба | Підказка | Пояснення |
|---|---|---|
| `123` | 0 Б, 0 К | жодної з цих цифр немає |
| `407` | 1 Б, 2 К | 4 на своєму місці, 0 і 7 переплутані |
| `470` | 3 Б | вгадано |

## Режими

- **Ти вгадуєш** — комп'ютер загадує число, ти відгадуєш.
- **Він вгадує** — ти загадуєш число на папері й підказуєш комп'ютеру бики та корови.
- **Дуель** — ви обидва загадуєте числа й вгадуєте по черзі. Нічия, якщо обидва вгадали в одному раунді.

Суперник має два рівні: **легкий** пам'ятає лише три останні підказки, **середній** враховує всі.

## Запуск

Відкрий `index.html` у будь-якому браузері.
